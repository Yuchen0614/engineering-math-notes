# 工程數學 · 手寫講義精讀

把 23 頁手寫工程數學講義（複數 → 向量 → 向量微積分 → 線性代數）整理成可互動的學習網站：每個例題都有「題目 → 思路 → 計算 → 答案 → 提醒」。

**線上閱讀：** https://yuchen0614.github.io/engineering-math-notes/

## 內容

- 原稿 23 頁 → 17 章 + 附錄，31 個例題卡（每題附「思路」與易錯提醒）
- 每章開頭「用一句話說」白話框，先用生活比喻講清楚在幹嘛
- 每章附原稿縮圖（點擊放大對照）、核心觀念框、「馬上練」自我檢查
- 術語中英對照 106 條（可即時搜尋）；章節標題與 English 列的術語可點開看中文意思
- 附錄：公式總表、全部例題速查表、原稿 5 處筆誤更正、考前 60 秒檢查清單
- 手機可讀、夜間模式、完全離線可用（KaTeX 與原稿圖都在本機）

## 使用方式

下載後直接雙擊 `index.html` 即可（不需伺服器、不需網路）。

```
index.html          網站本體（單一檔案，含所有內文）
pages/p01–p23.jpg   原稿掃描頁
assets/katex/       離線數學排版（KaTeX + 字型）
```

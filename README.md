## 筆記

原稿是上課手寫筆記，內容中有 3 處筆誤（p.4 的 $f(1+3i)$、p.10 保守場那句位勢差、p.18 電路第二條方程式），
站內對應例題的「提醒」都有標出並給正確版本。

反過來說，原稿有 3 處<b>看起來像筆誤、其實是對的</b>（舊版誤判並「改錯」了，已修正）：

| 原稿頁 | 原稿寫的 | 為什麼是對的 |
|---|---|---|
| p.4 | $\vec a=4\hat i+\hat k$ | 沒寫 $\hat j$ 代表係數是 0，所以 $\vec a+\vec b$ 的第二分量是 $0-5=-5$ |
| p.7 | $\vec a=[1,0,-2]$、$|\vec a|=\sqrt5$ | 第二個分量是 0，$\sqrt{1+0+4}=\sqrt5$；方向導數 $-\frac{4}{\sqrt5}$（負值） |
| p.17 | $A=[\,5\ \ -8\ \ 1\,;\,4\ \ 0\ \ 0\,]$ | $A$ 是 $2\times3$，轉置後是 $3\times2$（$A_{13}=1$ 會跑到第 3 列） |

三題的錯法都一樣：**把「沒寫的項」當成 1，或把矩陣少看一欄**。抄題時一格一格對，才不會把對的答案改錯。
